# Ethical marketing boundary

This repository is for ethical planning and schedule simulation only.

It must not be used for spam, fake engagement, fake reviews, impersonation, deceptive claims, dark patterns, political persuasion targeting, scraping private personal data, exploiting vulnerable audiences, or bypassing platform rules.

The default pipeline does not post to real platforms. Real posting adapters require human approval, API compliance, rate-limit handling, credential security, brand review, consent-aware data handling, and audit logging.
